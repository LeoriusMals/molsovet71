Молодёжный совет — концепт портала и кабинетов

Статические страницы сохранены:
- index.html — главная сайта.
- rating.html — отдельная страница рейтинга.
- molodezh_meropriyatiya.html — публичные мероприятия.
- admin.html / login.html — ранее созданные концепты; пока не заменены новой рабочей схемой.

Новый концепт:
- portal.php — серверный кабинет с разными главными страницами для Участника, Модератора и Администратора.
- setup_admin.php — CLI-скрипт создания первого администратора.

Роли и рабочий процесс:
1. Участник смотрит ближайшие мероприятия, отправляет отчёты и видит свои баллы.
2. Модератор получает задачи в стиле CRM, меняет статусы поручений, проверяет отчёты и одобряет/отклоняет их.
3. Администратор создаёт мероприятия, назначает ответственных модераторов, ставит задачи, создаёт учётные записи, утверждает отчёты и начисляет баллы.
4. Баллы начисляются только после утверждения отчёта администратором.

Безопасность:
- В базе хранится password_hash, а не пароль открытым текстом.
- Проверка роли выполняется на сервере для POST-действий.
- Формы используют CSRF-токен, запросы к БД параметризованы, HTML-вывод экранируется.
- Не храните пароли в HTML/JavaScript/localStorage и не публикуйте файл SQLite.
- Перед размещением установите PHP 8.1+ с PDO_SQLite и HTTPS.
- Обязательно задайте переменную окружения PORTAL_DB_PATH на путь вне публичного web-root.
- setup_admin.php запускается только из командной строки: php setup_admin.php. Не запускайте его через браузер.
- После создания первого администратора удалите setup_admin.php с сервера.
- Для продакшена потребуются также резервное копирование, восстановление пароля, аудит изменений и конфигурация сервера.

Запуск локально (если установлен PHP с pdo_sqlite):
1. Откройте терминал в папке server.
2. Задайте PORTAL_DB_PATH на путь за пределами публичной папки.
3. Создайте первого администратора командой php setup_admin.php.
4. Запустите тестовый сервер: php -S 127.0.0.1:8080 -t <папка-проекта>.
5. Откройте http://127.0.0.1:8080/portal.php

Важно:
Это прототип для проверки концепции, не готовая к публичному запуску production-система. Не публикуйте его в интернете без настройки сервера, HTTPS, закрытого хранения БД и тестирования.

Обновление концепта (22.10.2026):
- login.html перенаправляет на серверную авторизацию portal.php. После входа пользователь попадает в кабинет, соответствующий его роли (участник, модератор или администратор).
- У администратора в меню есть отдельный пункт «Управление рейтингом», открывающий rating.html.
- Администратор может создавать отделы и назначать отдел модератору/администратору при создании учётной записи. Для уже существующей базы добавлена миграция поля отдела.
- В текущей версии отделы группируют сотрудников и фиксируют зону ответственности; реальные отдельные наборы разрешений по отделам пока не реализованы — доступ по-прежнему определяется ролью.
