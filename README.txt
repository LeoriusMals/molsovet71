ПОРТАЛ МОЛОДЁЖНОГО СОВЕТА — ЛОКАЛЬНАЯ ВЕРСИЯ ДЛЯ ПРОВЕРКИ ИНТЕРФЕЙСА И ВХОДА

БЫСТРЫЙ ЗАПУСК НА MAC
1. PHP не нужен. Нужен Python 3 (обычно уже установлен на Mac).
2. Откройте папку проекта и дважды нажмите «Запустить_локальный_портал.command».
3. В браузере откроется http://127.0.0.1:8080/login.html.
4. При первом запуске создайте администратора: укажите ФИО, логин и пароль от 6 символов.
5. После входа создайте аккаунты участника и модератора в разделе «Учётные записи».
6. Сессия сохраняется в localStorage: между страницами и повторными открытиями вход не потребуется, пока вы не нажмёте «Выйти из аккаунта».
7. Остановить локальный сервер можно сочетанием Control+C в окне Terminal.

КАК РАБОТАЕТ ЛОКАЛЬНЫЙ ВХОД
- Вход выполняется по логину и паролю.
- Аккаунты, парольные строки и текущая сессия сохраняются в localStorage этого браузера.
- Роль аккаунта используется для выбора кабинета и отображения соответствующего интерфейса.
- В шапке страниц отображается круглый аватар, фамилия с инициалами и роль. Нажатие открывает меню профиля с полным ФИО, логином и кнопкой «Выйти из аккаунта».
- Сессия остаётся активной при переходах между страницами и перезапуске браузера, пока пользователь явно не выйдет из аккаунта.

ХРАНЕНИЕ ДАННЫХ
В этой версии авторизация и данные тестовых аккаунтов хранятся в localStorage браузера. Они не синхронизируются между разными браузерами или устройствами. Очистка данных сайта удалит локальные аккаунты и сессию.

ВАЖНО
Это прототип для проверки интерфейса и сценариев входа. Проверки доступа в статических HTML-файлах не являются настоящей защитой: пользователь может менять localStorage через инструменты разработчика. Не используйте реальные пароли и не публикуйте эту версию в интернете. Для реальной защиты понадобится серверная авторизация.

РАЗДЕЛ «ДОСКИ ЗАДАЧ» (tasks.html)
- Доступен администраторам и модераторам после авторизации.
- Администратор может создавать доски и назначать задачи активным аккаунтам с ролью «Модератор».
- Модератор видит задачи, назначенные ему, и может отправить задачу на проверку.
- В тикете доступны комментарии, хронология изменений, смена статусов и решение администратора.
- Данные демонстрационного раздела сохраняются локально в localStorage текущего браузера; синхронизации между разными устройствами без серверной базы данных нет.
