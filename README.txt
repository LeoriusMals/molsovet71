ПОРТАЛ МОЛОДЁЖНОГО СОВЕТА — ЛОКАЛЬНАЯ ВЕРСИЯ

ОТКРЫТИЕ САЙТА
1. Распакуйте архив.
2. Откройте папку «Молодёжный_совет».
3. Откройте файл index.html двойным щелчком.
4. Для перехода к разделам используйте меню самого сайта.

ХРАНЕНИЕ ДАННЫХ
Данные тестовой версии сохраняются локально в хранилище браузера (localStorage).
Они остаются в этом браузере и профиле, пока вы не очистите данные сайта/браузера.
Не очищайте данные браузера, если хотите сохранить тестовые записи.

Это локальная тестовая версия без PHP и серверной базы данных.
Для реальной синхронизации между разными браузерами и устройствами в будущем
будет подключено серверное хранилище.
